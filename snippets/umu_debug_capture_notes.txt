# UMU debug capture and environment flags notes

- UMU_DEBUG_CAPTURE: set this env var to a file path to capture child stdout/stderr into that file. The launcher will also write an environment snapshot to the same path with suffix .env.json.

Example (one-shot):
  UMU_DEBUG_CAPTURE=/tmp/umu-capture.log umu-run <exe>

- UMU_ASSUME_RUNTIME_READY: opt-in flag (1) to skip remote network probes and instead run a local runtime presence check. Only set if you know your local runtime/proton is installed and healthy.

- UMU_NO_RUNTIME: existing flag to instruct umu to skip using the steam runtime/pv-adverb path. Combined with the bypass snippet it will attempt to call a concrete proton binary directly.

- UMU_RUNTIME_UPDATE, UMU_HTTP_TIMEOUT, UMU_HTTP_RETRIES: existing knobs to control update behavior and urllib3 timeouts/retries.
